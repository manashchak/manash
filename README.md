# manashchak.github.io/manash

Personal website of Manash Chakraborty, Ph.D. — Software Engineer at KLA Corporation.

Built with [Showlit](https://github.com/pm25/showlit), a React-based personal website template.

## Development

```bash
npm install
npm run dev
```

## Deployment

Pushes to `main` trigger GitHub Actions to build and deploy to the `gh-pages` branch.
